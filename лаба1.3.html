Предметы для питомцев

Сухой корм

Сбалансированный корм премиум-класса для взрослых кошек и собак. Содержит витамины и минералы, поддерживает здоровье шерсти и пищеварения.

Игрушка-мячик

Прочный резиновый мяч для активных игр. Отлично подходит для апортировки и тренировок, безопасен для зубов питомца.

Лежак

Уютное спальное место. Съёмный чехол легко стирается, подходит для собак средних пород.

Поводок-рулетка

Удобный поводок длиной до 5 метров с тормозной системой. Идеален для прогулок в парке и тренировок послушания.

Клетка для грызунов

Просторная клетка с несколькими ярусами, поилкой и колесом. Подходит для хомяков, мышей и других мелких грызунов.

Аквариум

Стеклянный аквариум с фильтром и подсветкой. Отличный дом для рыбок и водных растений.
